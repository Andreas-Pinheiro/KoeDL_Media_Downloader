# Contributing / Como contribuir

**PT:** obrigado pelo interesse. O KoeDL é um projeto pequeno e a intenção é mantê-lo simples.

- **Encontrou um bug?** Abra uma [issue](../../issues/new/choose) informando a versão (rodapé do programa), o que foi feito e o que aconteceu. Se possível, anexe o `bin\app.log` (confira antes se não há dados pessoais).
- **Sugestões:** abra uma issue descrevendo o problema que a sugestão resolve. Nem toda sugestão é incorporada, para manter o programa leve.
- Descreva o caso de forma objetiva e mantenha o tom respeitoso.

**EN:** thanks for your interest. KoeDL is a small project and the intention is to keep it simple.

- **Found a bug?** Open an [issue](../../issues/new/choose) with the version (program footer), what you did and what happened. If possible, attach `bin\app.log` (check it for personal data first).
- **Suggestions:** open an issue describing the problem the suggestion solves. Not every suggestion is accepted, to keep the program light.
- Describe the case objectively and keep the tone respectful.
