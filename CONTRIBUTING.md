# Contributing / Como contribuir

**PT:** obrigado pelo interesse! O KoeDL é um projeto pequeno e a ideia é mantê-lo simples.

- **Achou um bug?** Abra uma [issue](../../issues/new/choose) com a versão (rodapé do programa), o que você fez e o que aconteceu. Se der, anexe o arquivo `bin\app.log` (confira antes se não tem nada pessoal).
- **Quer sugerir algo?** Abra uma issue de sugestão explicando o problema que isso resolve. Nem toda ideia entra, para o programa continuar leve.
- **Quer mexer no código?** Abra uma issue antes para combinarmos. O programa é um único `.bat` gerado a partir de várias partes; conte o que pretende mudar e eu explico como gerar.
- Seja gentil: aqui todo mundo está aprendendo.

**EN:** thanks for your interest! KoeDL is a small project and the goal is to keep it simple.

- **Found a bug?** Open an [issue](../../issues/new/choose) with the version (program footer), what you did and what happened. If you can, attach `bin\app.log` (check it has nothing personal first).
- **Want to suggest something?** Open a suggestion issue explaining the problem it solves. Not every idea gets in, to keep the program light.
- **Want to change the code?** Open an issue first so we can agree. The program is a single `.bat` generated from several parts; tell me what you plan to change and I will explain how to build it.
- Be kind: everyone here is learning.
