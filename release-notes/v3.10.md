KoeDL v3.10

This release changes how KoeDL is built and how it updates itself. The app looks and works the same.

### One file for you, readable sources for the project
`KoeDL.bat` is now generated from a source tree instead of being maintained as a single 714 KB file:
the batch launcher, the PowerShell backend, the C# window and installer, and the interface
(HTML/CSS/JS, translations and artwork) live in separate files under `src/`.
The build puts them back together into the same single-file `KoeDL.bat`, so nothing changes for
the people using it: download one file, double-click, done.

### Updates come from Releases
"Check for program updates" and the update banner now read the GitHub Releases API and download
the `KoeDL.bat` attached to the newest release, instead of fetching a file from the branch.
The "Update now / Not now" banner works exactly as before.

### Clearer errors
Failures that used to disappear silently now write a line to the log (Details > Log) and show a
short, friendly message in the interface — never a raw technical error.

### Same project, same files
`Media-Downloader.bat` is still published, byte-identical to `KoeDL.bat`, so older installs keep
updating normally.

### Downloads
| File | What it is |
| --- | --- |
| `KoeDL.bat` | The app. Single file, no install. |
| `Media-Downloader.bat` | Identical copy kept for old installs. |
| `KoeDL-Setup.exe` | Installer: pick the folder, installed or portable. |
| `KoeDL.exe` | The app window as an executable. |
| `SHA256SUMS.txt` | SHA256 of every file above. |

Check a download before running it:

```
certutil -hashfile KoeDL.bat SHA256
```

Compare with the value on the matching line of `SHA256SUMS.txt`.

⚠️ The executables are not code-signed, so Windows SmartScreen will warn: click More info, then
Run anyway. If your antivirus objects to the `.exe`, use `KoeDL.bat` — it does exactly the same thing.

## Português (resumo)

O KoeDL agora é montado a partir de fontes organizadas (backend PowerShell, C#, interface e assets)
e continua sendo distribuído como um único `KoeDL.bat`. A verificação de atualização passa a usar a
API de Releases do GitHub e o arquivo anexado à release mais recente. Erros que antes sumiam agora
aparecem no log com uma mensagem amigável na tela. O `Media-Downloader.bat` continua publicado para
as instalações antigas. Confira o SHA256 em `SHA256SUMS.txt` antes de executar.
